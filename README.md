### 领了券却用不了，通常是这几个原因

按官方文档列出的高频原因，可以对着排查：

1. 适用产品不符——通用券不覆盖云通信、域名、实物商品和云市场三方商品
2. 券已过有效期
3. 订单类型不在范围内，比如券只支持新购、不支持续费或升级
4. 时长不满足条件，有些券要求购买一定月数以上
5. 满减券的订单金额没到门槛
6. 优惠互斥——订单已经享受了其他折扣或活动价
7. 手机端异常——换浏览器或电脑端再试
8. 活动专项限制，比如大学生300元券只能在学生用券中心使用

其中“优惠互斥”最容易被误解：你以为券能和活动价叠着用，规则里写的却是二选一。下单前把券详情页的使用条件看完，能省掉大部分折腾。

## 关于阿里云老用户优惠的常见问题

**老用户为什么领不到新用户价？**
低价新用户价本质是拉新补贴，平台用差价换新客户。老用户的优惠逻辑不同，分布在续费折扣、升级专项、新老同享活动和优惠券里。判断一个活动老账号能不能参加，最可靠的办法是看规则原文里有没有“新老用户同享”这类字样，没写就默认按新用户限定处理。

**续费比新购贵，怎么办？**
三个动作：续费前先领券，支付页会自动匹配可用券；存储类产品认准“续费同价”的活动再买；ECS 到期前留意老用户专项，升级配置的折扣经常比原样续费更大。

**一笔订单能用几张优惠券？**
一张。但一张券可以在有效期内反复抵扣多个订单，直到余额用完；按量付费的账单出账后，系统会自动用多张券依次抵扣。

**优惠券能和活动价叠加吗？**
看具体券的规则。部分券明确不支持与其他优惠同时使用，这也是券显示“不可用”的高频原因。支付页会自动筛选展示可用的券，页面没显示，基本就是互斥或条件不符。
